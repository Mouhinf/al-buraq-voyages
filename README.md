# Al-Buraq Voyages ✈️

**Maison de Voyages d'Exception & Pèlerinages Sur-Mesure**

Application web moderne conçue avec **Next.js 15 (App Router)**, **Tailwind CSS**, **TypeScript** et **Lucide Icons**, selon l'archétype **Editorial & Haute Culture** du design system Bespoke UI/UX.

---

## 🌟 Points Forts

- **Design Haute Couture & Anti-Cliché IA** : Typographie littéraire *Playfair Display* & *Plus Jakarta Sans*, palette ivoire chaud / lin (`#FBF9F5`) et or antique.
- **Grille Bento Asymétrique** : Mise en scène immersive des destinations phares (Istanbul, Médine & La Mecque, Andalousie, Dubaï, Santorin, Séoul).
- **Conciergerie Privée Interactive** : Formulaire de demande de devis sur-mesure avec confirmation en direct.
- **Architecture 4 Couches Stricte** :
  1. `src/types/` : Contrats et typages stricts TypeScript.
  2. `src/lib/data/` : Services de données et catalogues typés.
  3. `src/components/` : Primitives d'interface modulaires (< 150 lignes).
  4. `src/app/` : Vues de composition légères (< 250 lignes).
- **Performances & Sécurité** : 100% audité et validé avec GuardVibe (Score A - 100/100).

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 20+
- pnpm (recommandé) ou npm

### Installation
```bash
git clone https://github.com/Mouhinf/al-buraq-voyages.git
cd al-buraq-voyages
pnpm install
```

### Développement
```bash
pnpm dev
```
Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### Build de Production
```bash
pnpm build
pnpm start
```
